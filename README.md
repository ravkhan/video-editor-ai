# video-editor-ai

Веб-редактор видео с автоматическими субтитрами (Python, FastAPI, faster-whisper, FFmpeg).

## Возможности
- загрузка видео (MP4, MOV, MKV, WebM, AVI…); форматы, которые браузер не воспроизводит, перекодируются для просмотра;
- автоматическое распознавание речи Whisper с пословными таймкодами и умной разбивкой на субтитры (по паузам, длине и концам предложений), перевод на английский;
- редактор: правка текста и таймингов, «начало/конец = текущая позиция», разделение (Alt+Enter), объединение, сдвиг всех субтитров, таймлайн;
- стиль: шрифт, размер, цвета, обводка или подложка, позиция, живой предпросмотр;
- экспорт SRT / WebVTT / ASS и рендер MP4 с вшитыми субтитрами; импорт SRT/VTT.

## Запуск
Нужны Python 3.10+ и FFmpeg (с libass).

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:create_app --factory --host 0.0.0.0 --port 8000
```

Откройте http://localhost:8000.

Переменные окружения: `DATA_DIR` (где хранить проекты, по умолчанию `./data`), `WHISPER_MODEL` (по умолчанию `small`),
`WHISPER_DEVICE` (`auto`/`cpu`/`cuda`), `WHISPER_COMPUTE_TYPE` (например `int8`), `MAX_UPLOAD_MB`, `WORKERS`.
